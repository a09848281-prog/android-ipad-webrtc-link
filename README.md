# Android ⇄ iPad WebRTC Link

Androidのカメラ・マイクをiPadへ送り、iPadからはPTT（押している間だけ送信）でAndroidへ音声を返す個人利用向け試作です。

## 構成

- GitHub Pages：画面の配信
- Google Apps Script：SDP/ICE候補などのシグナリング情報交換のみ
- WebRTC：映像・音声を端末間で直接通信
- データベース・録音・録画保存：なし

## 1. GASのセットアップ

1. [Google Apps Script](https://script.google.com/) を開き、新しいプロジェクトを作成します。
2. 最初からある `コード.gs` の内容をすべて消し、`gas/Code.gs` の内容を貼り付けます。
3. 保存します。
4. 右上の「デプロイ」→「新しいデプロイ」を選択します。
5. 種類は「ウェブアプリ」。
6. 次のように設定します。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
7. 「デプロイ」を押し、表示された `https://script.google.com/macros/s/.../exec` のURLをコピーします。

GASのURLは秘密の認証情報ではありませんが、接続コードは推測されにくいものではないため、知らない人に共有しないでください。ソースコードに個人情報やAPIキーを追加しないでください。

## 2. GitHub Pagesの公開

1. GitHubリポジトリの Settings → Pages を開きます。
2. Build and deployment の Source を「Deploy from a branch」にします。
3. Branch を「main」、フォルダーを「/ (root)」にして Save。
4. 数分待って、次のURLを開きます。

https://a09848281-prog.github.io/android-ipad-webrtc-link/

## 3. 接続方法

1. AndroidとiPadの両方で同じPages URLを開きます。
2. 両方に同じGAS WebアプリURLを入力して「URLを保存」します。
3. Android側で「カメラ・マイクを開始して接続待機」を押し、権限を許可します。
4. Android画面に出た6桁コードをiPad側へ入力します。
5. iPadで「接続する」を押し、マイク権限を許可します。
6. iPadのPTTボタンを押している間だけ、iPadのマイク音声がAndroidへ送信されます。

## 新機能版：ロック画面・カメラ切り替え・自動再接続

この開発版では、Android側のネイティブForeground Serviceを使います。

1. Androidアプリを初回起動し、カメラ・マイク・通知などの許可を済ませます。
2. Android側でGAS URLを設定し、「WebRTCを開始」を押して接続待機にします。
3. iPad側で6桁コードを入力して接続します。
4. 接続後、iPadの映像ツールバーにある「カメラ切り替え」でAndroidの前面／背面を切り替えます。
5. Androidの画面をロックしても、Foreground Serviceの通知が表示されている間は通話を維持する設計です。
6. 一時的にネットワークが切れた場合は、Android側がICE Restartを試して自動再接続します。

**重要な制限**
- Androidの初回起動と権限許可は必須です。アプリを一度も起動していない状態から、iPadだけでAndroidのカメラ・マイクを遠隔起動することはできません。
- Androidの「強制停止」、アプリ情報画面からの強制終了、電源再起動直後の未起動状態からの自動接続は保証できません。
- OSがプロセスを回収した場合のForeground Service復元はベストエフォートです。
- 通話中は画面消灯後もCPUを維持するため部分WakeLockを使用します。バッテリーを消費するので、通話終了時はAndroidアプリの「サービスを停止」または通知の「停止」を押してください。
- iPad Safariがバックグラウンドで停止した場合、Safariを前面に戻してからシグナリング処理が再開することがあります。
- STUNのみのため、ネットワークによってはTURNサーバーが必要です。

## 制限・注意

- 最初は両端末を同じWi-Fiに接続し、ブラウザを前面に表示してテストしてください。
- STUNのみの構成です。ネットワークによってはP2P接続できません。その場合はTURNサーバーが必要です。
- ブラウザでは画面ロック中やバックグラウンドでカメラ・マイクが停止することがあります。ロック中の新規取得や常時取得は保証できません。
- iPad側はマイク許可が必要です。PTTは押している間だけ音声トラックを有効にします。
- 接続コードは6桁の簡易コードです。機密通信・不特定多数向けサービスには使用しないでください。
- GAS CacheServiceは一時保存領域です。通信ログの永続保存には使いませんが、メッセージは最大6時間程度残る場合があります。
- この試作は実機での接続検証前です。ブラウザ・ネットワーク環境により動作が異なります。
